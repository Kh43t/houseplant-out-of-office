The funniest out-of-office auto-reply a houseplant would send, 120 characters or fewer: a fern by the window, unwatered since March, and still the only one in the office with a growth plan.

## Run it

```sh
node main.ts
```

It writes the auto-reply to `/output/entry.txt` — one line, no trailing newline, deterministic on every run.
